## 接口约定

- `ImageParameters(width=1920,height=1080,top=3,offset=2)`：冻结对象，仅支持1080/1200高度，其他布局值固定。默认实例`DEFAULT_IMAGE`。字段/属性：`shape=(height,width)`、`tx_roi/rx_roi=(y0,y1,x0,x1)`（右下端不含）、`active_width/active_height`、`pixels`、`interleave_shape=(959,height-3)`、`wire_bytes`、`capacity`。几何单位像素，长度/容量单位字节。
- `image_parameters(config,'tx'|'rx')`：入口解析；公共width/height为默认值，可选`tx_mode`/`rx_mode`只允许width/height覆盖。`config.load`验证两方向，返回值仍为可JSON序列化的原配置字典。
- `wire_to_image(wire,layout='sequential',parameters=DEFAULT_IMAGE)`；`image_to_wire(image,captured=True,layout='sequential',parameters=DEFAULT_IMAGE)`。协议使用`layout='column'`；captured=False为源图TX ROI，True为固定RX ROI。
- `capacity(n=255,k=247,parameters=DEFAULT_IMAGE)`；`encode_frame(...,identity=None,parameters=DEFAULT_IMAGE)`；`decode_header/decode_wire/decode(wire,parameters=DEFAULT_IMAGE)`。原参数顺序保留；wire不含尺寸，调用方必须传入相同方向参数。
- `FileSource(path,parameters=DEFAULT_IMAGE)`的`count/read(index)`和`DiskReassembler(partial,destination,parameters=DEFAULT_IMAGE)`的`add/finish`使用相同容量。内存`Reassembler()`继续接收已解码帧。
- `calibration.pattern(seed,parameters=DEFAULT_IMAGE)`、`gray(image,parameters=...)`、`compare(source,captured,orientation,parameters=...)`、`measure(source,captured,parameters=...)`、`receive_wire(image,result,parameters=...)`。标定结果字段保持原样，roi使用上述坐标约定，pixels随参数变化。
- 显示后端`display_one(config,...)`使用tx参数；`capture_frames(config,metadata,...)`使用rx参数，metadata继续区分requested/reported/shape。`codec_timings(parameters=DEFAULT_IMAGE)`测量指定几何的本地编解码链路。

```python

from visual_link.core.protocol import encode_frame, decode

rx = ImageParameters(height=1080)  # 独立接收容量1,000,103字节
image, wire = encode_frame(b'example', parameters=tx)
```
