# 硬件准备

## 连接

两端分别称为 A、B，每端提供一个 HDMI 输出和一块 USB 采集卡：

- A 的 HDMI 输出 → B 端采集卡的 HDMI 输入；采集卡 USB 接 B。
- B 的 HDMI 输出 → A 端采集卡的 HDMI 输入；采集卡 USB 接 A。

两端均显示通信图案，即使只接收文件也需要反向视频链路传递确认消息。

## 显示与采集

将传输屏设为 1920×1080 或 1920×1200，缩放 100%，方向为正常横屏。两个方向可以使用不同分辨率。传输期间保持桌面登录、屏幕常亮和通信窗口完整显示。

采集卡通过 V4L2（Linux）或 DirectShow（Windows）提供对应分辨率的 BGR3/RGB24 原生像素。关闭其他占用采集卡的应用。

## 设备配置

编辑对应的 JSON 配置：

| 字段 | 含义 |
|---|---|
| `backend` | `windows` 或 `linux` |
| `device` | 采集卡编号，从 0 开始；Linux 也可填 `/dev/video0` |
| `monitor` | 传输屏编号，从 0 开始 |
| `candidate_modes` | 候选尺寸，默认 `[[1920,1080],[1920,1200]]` |

Windows 示例选择第 2 块屏幕（`monitor: 1`）；Linux 示例选择第 1 块屏幕（`monitor: 0`）。按设备连接修改编号。

程序默认保留当前受支持的显示尺寸，并独立协商两个方向。使用 1200p 时，将该发送端传输屏设为 1920×1200。采集模式跟随对端发送尺寸，图像位置和灰度由程序自动标定。会话退出后恢复原显示模式。
